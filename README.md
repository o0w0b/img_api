## 改动

- 修改随机图片返回逻辑，减少重复命中
- 启动时缓存图片链接列表，提升接口性能
- 修复 Windows 文本行尾导致的链接异常问题
- 前端页面支持实时预览、深浅色模式等

## 图片链接生成工具（Windows）

项目内的 `tool` 文件夹提供了一个 Windows 批处理脚本，用来快速生成图片链接文件

生成的 `.txt` 文件可以直接用于本项目，无需额外处理

### 使用方式
双击脚本后，根据窗口提示操作即可完成
